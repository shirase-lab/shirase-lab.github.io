# 配信ステッカー（stickers/）

うちわつくーるアプリの**配信ステッカー**（作者制作・装飾用の透過 PNG）の置き場。

- `index.json` … マニフェスト（`{ "schema":1, "stickers":[...] }`）。各エントリ:
  - `id`（一意・URL安全）/ `title` / `thumbUrl`（相対可・PNG）/ `fileUrl`（相対可・**透過PNG**）
  - `updatedAt` / `minAppVersion` / `tags`（分類・任意）/ `description`（任意）
- `<id>.png` … ステッカー実体（透過 PNG・長辺 1024px 目安）。
- `thumb/<id>.png` … 一覧サムネ（320px 目安）。

アプリはこれを GET のみで取得（送信なし・端末内キャッシュ）。**投稿機能は無い**（作者制作のみ）。
タップで DL してキャンバス中央へ配置（既に切り抜き済みなので背景削除は挟まない）。
アップロード/削除はアプリのデバッグビルド（配信ステッカー・ギャラリー画面の「＋」/長押し）から。
**タグの編集はブラウザ管理画面 `admin.html`**（PAT で接続→`index.json` のタグを編集→保存。noindex）。
